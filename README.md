# Influ Affi Level up by Tanguy - Ai Creator E-book

เว็บ Ebook ออนไลน์ธีมขาว ดำ ชมพู ฟอนต์ Kanit รองรับมือถือและเดสก์ท็อป สำหรับ Creator / Influencer / Affiliate

## โครงสร้างเนื้อหา

- 1. วิเคราะห์ตัวตน
- 2. วางแพลนโพสต์
- 3. สรุปสินค้า
- 4. Hook
- 5. กรอบไลฟ์

## ไฟล์หลัก

- `index.html` - หน้า Ebook ออนไลน์
- `styles.css` - ดีไซน์ responsive และธีมสี
- `app.js` - โหมดหนังสือ/โหมดเว็บไซต์ สารบัญ และปุ่มคัดลอก Prompt
- `assets/` - โลโก้และภาพประกอบ
- `.nojekyll` - รองรับ GitHub Pages

## การใช้งาน

เปิด `index.html` ใน browser ได้ทันที หรืออัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages

## Deploy ด้วย GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดเข้า repository
2. ไปที่ `Settings > Pages`
3. เลือก `Deploy from a branch`
4. เลือก branch `main` และ folder `/root`
5. รอ GitHub สร้างลิงก์เว็บ
