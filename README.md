# THE GOOD MILLION - AI Creator Ebook

เว็บ Ebook ออนไลน์ธีมฟ้า ฟอนต์ Kanit รองรับมือถือ/เดสก์ท็อป และจัดเนื้อหาใหม่ให้เหมาะกับ Creator

## ไฟล์หลัก

- `index.html` - หน้า Ebook ออนไลน์
- `styles.css` - งานดีไซน์ responsive
- `app.js` - สารบัญ active state, ปุ่มบทก่อนหน้า/บทถัดไป, โหมดอ่าน
- `assets/` - ไฟล์ภาพตัวอย่างและภาพประกอบเว็บ
- `.nojekyll` - รองรับ GitHub Pages

## วิธีใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรืออัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages

## Deploy ด้วย GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repository
2. ไปที่ Settings > Pages
3. เลือก Deploy from a branch
4. เลือก branch ที่เก็บไฟล์ และเลือก `/root`
5. รอ GitHub สร้างลิงก์เว็บ
